## Acquisition and Verification Notes

- Every acquired dataset remains separate under `data/raw/`; no images, masks, or labels were merged across datasets.
- The FUSeg repository contains unrelated source-repository material, including a Medetec-derived directory. That directory was not treated as the Medetec acquisition; Medetec was acquired separately from the official Medetec website.
- The Mendeley V3 archive was downloaded from the official public-file URL returned by the official Mendeley Data record. Its SHA-256 matched the official API metadata before extraction.
- The Lower Limb V3 archive’s delivered directory names and dimensions were preserved exactly. No resizing, renaming, relabeling, or mask repair was performed.
- The Mendeley landing-page metadata identifies the release as Version 3, although the embedded description still contains a stale Version 2 line. The archive contains 2,757 files under `Nomal` rather than the description’s stated 2,575 Normal images; the observed total is 8,129 and matches the stated dataset total.
- Medetec is an image-domain resource only in this acquisition. No annotations or masks were fabricated.
- The official DFU organizer page states that students/research assistants must apply through an authorized institutional representative and that an institutional email, intended-use details, and an approved license agreement are required.
