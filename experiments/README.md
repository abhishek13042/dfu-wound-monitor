# Experiments

This directory stores experiment definitions, execution notes, tracked runs, and empirical findings.

## Experiment Organization

Future experiment runs will be organized hierarchically and document:
- **Experiment Configuration**: Hyperparameters, hardware details, and environment metadata.
- **Model Configuration**: Architecture choices, backbones, pre-trained weights, and loss functions.
- **Dataset Version**: Exact dataset splits, version hashes, and augmentation pipelines.
- **Metrics**: Quantitative performance scores (e.g., Dice, IoU, mAP, MAE) across validation/test sets.
- **Visualizations**: Representative qualitative outputs, segmentation overlays, and error cases.
- **Logs**: Execution logs and training curves.
- **Conclusions**: Engineering insights, failure analyses, and decisions regarding baseline progression.
